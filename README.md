# Senda de Palabras

A lightweight bilingual (English/Spanish) static portfolio for writing and translation.

## Current prototype

The first version is a single-page site in `index.html`. It includes:
- English/Spanish language toggle
- Responsive layout for desktop and mobile
- Sections for selected work, translations, writing, longer projects, and About
- Explicit labels for works in progress and contemporary creative writing

There are no build tools, external JavaScript dependencies, or framework requirements.

## Preview locally

Open `index.html` in a browser. For a local server, run:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Choose **Pages** in the sidebar.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site; the published URL will appear in the Pages settings.

## Before public launch

- Review every project description and status for accuracy.
- Replace provisional selections after reviewing the final texts.
- Add a fuller About/CV page only when biography, education, and credentials are ready to publish.
- Add source editions, credits, and permissions information for translations and adaptations.
- Check rights before publishing translations of modern copyrighted works.
- Test both languages, keyboard navigation, mobile layouts, and all links.
- Consider a custom domain after the site structure and name are settled.

## Editorial note

This is a curated portfolio, not a complete archive. Translation, adaptation, commentary, and original writing should be clearly distinguished. Contemporary sutra-inspired creative writing should not be presented as a historical or canonical Buddhist text.
